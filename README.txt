PAYROLLPRO DESKTOP — Sri Lanka HR / Attendance / Payroll

FEATURES
- Windows desktop / local SQLite database / no VPS required
- Employee master data + EPF number + bank details
- Manual attendance and attendance corrections
- OT, absent, leave and holiday status
- Configurable earning and deduction categories
- Salary advances, loans, shortage and other deductions can be entered as categories
- Monthly payroll calculation
- EPF: employee 8%, employer 12%
- ETF: employer 3%
- Separate payroll / EPF / ETF / attendance / deduction CSV reports
- Company profile and PNG logo
- Logo shown in app header and branded payslips
- Database backup
- Payslips generated as printable HTML (Windows Print -> Microsoft Print to PDF)

RUN FROM SOURCE
1. Install Python 3 on Windows.
2. Double-click run.bat.

BUILD EXE
1. On Windows, double-click build_exe.bat.
2. The finished EXE will be in dist\PayrollPro.exe.

IMPORTANT
Fingerprint integration is hardware/model dependent. This build includes the attendance layer and manual correction workflow. For direct biometric sync, provide the exact fingerprint device brand/model and SDK/protocol.
